# 모델 평가 리포트

`ml/train.py` 실행 결과 (재현 가능, `python ml/train.py`로 동일 결과 재생산). 원자료는
`ml/reports/results.json`.

## 1. 데이터 누수 수정 전후 비교

기존 `final_model.ipynb`는 `train_test_split(X, y, test_size=0.2)`을 완전 랜덤으로 수행했다.
같은 선수의 여러 시즌 row가 데이터셋에 함께 있는 상태에서 이렇게 나누면, 한 선수의
2022시즌이 train에 2023시즌이 test에 들어가는 식으로 같은 선수 정보가 양쪽에 걸쳐
새어나간다. 이 프로젝트에서는 `GroupShuffleSplit(groups=선수명)`으로 선수 단위 분할로
바꿔 재검증했다.

| 포지션 | 데이터 수 (선수 수) | 기존(랜덤 분할) R² | **수정(선수 그룹 분할) R²** | RMSE (그룹 분할) |
|---|---|---|---|---|
| 공격형 미드필더 | 1,012 (336명) | 68.7% | **77.4%** | €12.2M |
| 수비형 미드필더 | 1,378 (422명) | 69.0% | **66.8%** | €13.8M |
| 스트라이커 | 1,764 (607명) | 75.0% | **67.4%** | €10.4M |
| 윙어 | 1,357 (462명) | 75.2% | **62.1%** | €15.9M |
| 중앙 미드필더 | 1,455 (501명) | 77.6% | **69.0%** | €8.9M |
| 중앙 수비수 | 2,511 (868명) | 75.6% | **76.8%** | €7.9M |
| 측면 미드필더 | 356 (162명) | 48.4% | **40.3%** | €5.3M |
| 측면 수비수 | 1,804 (627명) | 75.8% | **67.9%** | €6.7M |

8개 포지션 중 6개에서 선수 그룹 분할 R²가 기존보다 낮게 나왔다 — 기존 랜덤 분할이
데이터 누수로 인해 실제보다 낙관적인 성능을 보고하고 있었다는 뜻이다(윙어 -13%p,
스트라이커 -8%p 등). 공격형 미드필더와 중앙 수비수는 오히려 그룹 분할에서 더 높게
나왔는데, 이는 어느 선수가 test에 걸리느냐에 따른 표본 변동으로 보이며(각 그룹의
선수 수가 수백~천 명 수준이라 완전히 안정적이진 않음), 누수가 없었다는 의미는 아니다.

측면 미드필더는 표본이 356건(162명)으로 8개 중 가장 적고 R²도 가장 낮다(40.3%) —
데이터가 부족한 포지션이라는 한계로 해석한다.

## 2. 과적합 방지 (조기 종료)

기존 하이퍼파라미터(Optuna로 튜닝된 것으로 추정, `max_depth` 최대 19, `n_estimators`
최대 1,900)는 수천 건 규모 데이터에 비해 과도하게 깊고 큰 트리였다. 이번엔 선수 단위로
분리한 내부 검증 세트에 대해 `early_stopping_rounds=50`을 적용해 실제 사용된 트리
개수(`best_iteration`)를 제한했다:

| 포지션 | 설정된 n_estimators | 실제 사용된 트리 수 |
|---|---|---|
| 공격형 미드필더 | 1,900 | 148 |
| 수비형 미드필더 | 1,400 | 278 |
| 스트라이커 | 1,600 | 436 |
| 윙어 | 1,400 | 65 |
| 중앙 미드필더 | 1,600 | 58 |
| 중앙 수비수 | 1,100 | 408 |
| 측면 미드필더 | 1,700 | 443 |
| 측면 수비수 | 1,400 | 213 |

대부분 설정값의 10~30% 수준에서 조기 종료됐다 — 원래 파라미터가 상당히 과도하게
설정되어 있었음을 뒷받침한다.

## 3. 피처 중요도 (포지션별 상위 5개)

전 포지션에서 `log_전시즌_시장가치`(작년 시장 가치의 로그값)가 1위이지만, 조기 종료
적용 후 비중이 13~31% 수준으로 기존(28~39%)보다 다소 완화됐다.

| 포지션 | 상위 피처 (중요도) |
|---|---|
| 공격형 미드필더 | log_전시즌_시장가치(27.5%), 상대편 박스 내 터치(5.6%), 나이²(4.8%), 시즌종료 나이(4.7%) |
| 수비형 미드필더 | log_전시즌_시장가치(28.6%), 나이²(11.0%), 시즌종료 나이(10.2%), 터치(2.8%) |
| 스트라이커 | log_전시즌_시장가치(31.1%), 시즌종료 나이(8.4%), 나이²(7.9%), 상대편 박스 내 터치(4.0%) |
| 윙어 | log_전시즌_시장가치(15.0%), 상대편 박스 내 터치(9.2%), 나이²(5.1%), 시즌종료 나이(4.2%) |
| 중앙 미드필더 | log_전시즌_시장가치(21.9%), 나이²(7.3%), 시즌종료 나이(5.9%), 득점_변화량(4.2%) |
| 중앙 수비수 | log_전시즌_시장가치(13.0%), 성공한 패스(10.5%), 나이²(8.7%), 시즌종료 나이(8.2%) |
| 측면 미드필더 | log_전시즌_시장가치(30.2%), 시즌종료 나이(6.7%), 나이²(6.4%), 상대편 박스 내 터치(5.7%) |
| 측면 수비수 | log_전시즌_시장가치(19.5%), 터치(10.7%), 시즌종료 나이(6.3%), 나이²(6.0%) |

**해석의 한계**: "작년 가치"가 가장 강한 예측 변수라는 건, 이 모델이 성과 지표로부터
가치를 새로 추정한다기보다 "작년 가격 + 나이·최근 폼에 따른 보정"에 가깝다는 뜻이다.
시장가치는 원래 전년도 값과 강한 자기상관이 있어 자연스러운 결과이지만, "선수 활약이
얼마나 시장가치에 기여하는가"를 보려면 이 피처를 제외한 별도 모델과 비교하는 것이
더 적절하다 (추후 개선 과제로 남김).

과소평가되고, 반대로 전성기가 지났거나 스탯 대비 고평가된 선수는 과대평가된다.

**과소평가 (실제 가치가 예측보다 훨씬 높음)**

## 5. 모델 선택: XGBoost vs LightGBM

이전 실험(`docs/archive/_deprecated/code2/analysis_code_1112.ipynb`, Optuna 기반 비교,
이번 재검증에서는 재실행하지 않고 과거 결과를 인용)에서 XGBoost와 LightGBM을 비교한
결과, 이 데이터셋 규모(포지션당 수백~수천 건)에서는 XGBoost가 근소하게 더 안정적인
성능을 보여 XGBoost를 최종 채택했다.

## 6. 알려진 한계
1. **측면 미드필더**는 데이터가 356건(162명)으로 가장 적어 R²(40.3%)가 다른 포지션 대비 크게 낮음.
2. **슈퍼스타 과소평가**: 시즌 스탯만으로는 브랜드/하이프 요인을 설명 못함 (4장 참고).
3. **작년 가치 의존도**: 데뷔 시즌처럼 "작년 가치"가 없는 신인 선수에 대한 예측 정확도는 검증되지 않음.
4. **그룹 분할도 완벽하지 않음**: 여전히 같은 선수의 인접 시즌이 아닌, 무작위 선수 단위 분할이라 "미래 시즌 예측"이라는 실제 배포 시나리오보다는 관대한 평가 방식임. 더 엄격한 검증은 시즌 기준 시간 분할(과거 시즌 학습 → 최신 시즌 테스트)이며 향후 과제로 남김.
